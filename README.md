# Bible Study App (Name Pending)

A Bible Study Application aimed at customization and user friendliness. Currently is, and not all features are implemented.

## Goals

- Open Source
- Local: no external server, or need for a internet connecting
- Customizable:
  - Word by word highting, not just restricted to verses
  - User defined Cross-References
  - Importing maps/images
  - Markdown support for inserts
  - Margin/Footnotes
  - Extra notes
- Bible Dictionary/Concordance integration:
  - Strings
  - Browns Driver Briggs
- Multiple Bible Versions (in the public domain)
  - KJV
  - ASV
  - YLT
- Convertible to pdf
  - Extra formatting settings
  - Printer friendly mode
